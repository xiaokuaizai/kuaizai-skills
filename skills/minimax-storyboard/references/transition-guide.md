# 转场填写规范

本规范规定导演分镜总表和 SEG 连续性交接中的「转场」信息写法。HTML 总表只展示画面锚点，不承载转场字段。

## 1. 基本定位

- **转场不是必需字段**。大多数 SEG 之间默认使用硬切，不需要特别说明。
- 只有当转场方式会影响观众理解、连续性或生成提示词时，才需要写出转场。
- 转场信息**不写入尾帧锚点**，应记录在该 SEG 的 `Continuity Handoff` 字段中。

## 2. 填写位置

```text
尾帧锚点：安琪面部特写，视线从江彻移向登机口方向，表情从平静转为轻微惊讶。
Continuity Handoff：淡入下一段
```

```text
尾帧锚点：江彻和安琪并排坐在班车后排，车窗外景色流动，光线由暖橙转为冷灰。
Continuity Handoff：硬切
```

## 3. 内容要求

1. **简短**：只写一个转场词或一个极短短语，例如：
   - `硬切`
   - `淡入`
   - `淡出`
   - `叠化`
   - `黑场`
   - `白场`
   - `声音桥`
   - `动作匹配`
   - `视线匹配`
   - `时间跳跃`
   - `空间重置`

2. **不提前描述下一段内容**：
   - ❌ 错误：`切到机场大厅，江彻抬头看航班信息`
   - ✅ 正确：`硬切`
   - ❌ 错误：`淡入，下一段安琪在值机柜台前`
   - ✅ 正确：`淡入`

3. **不重复剧情**：转场说明只描述「衔接方式」，不描述「衔接内容」。

## 4. 需要写转场的常见情况

| 情况 | 写法示例 |
|------|---------|
| 时间跳跃 | `时间跳跃：三小时后` |
| 空间重置 | `空间重置：转场至机场大厅` |
| 情绪停顿 | `淡出` |
| 新场景开场 | `淡入` |
| 动作连续剪辑 | `动作匹配` |
| 视线引导切换 | `视线匹配` |
| 音效/对白提前进入 | `声音桥` |
| 硬切但有明确轴线/方向变化 | `硬切，轴线重置` |

## 5. 默认规则

- 无特殊说明时，SEG 之间默认使用**硬切**。
- 硬切时，下一段首帧锚点必须重复上一段尾帧的关键细节，确保连续性。
- 时间跳跃或空间重置时，必须在 `Continuity Handoff` 中明确写出，避免模型默认延续同一时空。

## 6. 与 Minimax H3 提示词的关系

转场词本身不进入 Minimax H3 视频段提示词。提示词只描述该 SEG 内部的画面内容。跨段转场逻辑通过「首帧锚点 / 尾帧锚点」和「Continuity Handoff」来保证。

## 7. HTML 总表中的位置

在导演分镜总表 HTML 中，不设置单独的「转场」字段，也不在「尾帧锚点」中追加括号。转场只保留在 Markdown SEG 表的 `Continuity Handoff` 字段中。HTML 示例：

```html
<div class="field">
  <div class="label">尾帧锚点</div>
  <div class="value">安琪面部特写，视线从江彻移向登机口方向，表情从平静转为轻微惊讶。</div>
</div>
```
