# 导演分镜表到故事板参考图

> 本规范说明：当成品 `*_director_full_table.html` 已经定稿后，如何把它按 SEG 拆成一张张「故事板参考图」，供后续环节（如 Minimax H3 提示词配图、模型参考、审阅）使用。
>
> 它不替代 `references/故事板HTML制作规范.md` 的 HTML 制作规则；只负责**从 HTML 总表导出单 SEG 截图**这一步。

本步骤是阶段 E 的强制交付环节。所有 SEG 都必须导出故事板参考图、登记并上传；缺少任一 SEG 截图时不得完成阶段 E，也不得进入阶段 F。

---

## 1. 使用时机

在以下步骤完成后执行：

1. `Shot List` 与 `Minimax H3 Segments` 已锁定。
2. 所有单镜头分镜图已通过 QA。
3. HTML 总表 `*_director_full_table.html` 已生成并按 `references/故事板HTML制作规范.md` 校验通过。

---

## 2. 输出位置

在 HTML 总表同级目录下创建文件夹：

```text
storyboard_output/
├─ *_director_full_table.html      # 已生成的总表
├─ 故事板参考图/                    # 本规范生成的截图
│  ├─ SEG-01-故事板参考图.png
│  ├─ SEG-02-故事板参考图.png
│  └─ ...
└─ ...
```

---

## 3. 截图要求

### 3.1 内容完整性

- **每一张图对应一个 SEG**：只截 `<div class="seg-row">` 区块，不能把两个 SEG 拼到一张图里。
- **必须包含完整 3 栏**：
  - 左栏：段级拼接图
  - 中栏：SEG 信息、镜头表、首/尾帧锚点、台词/声音
  - 右栏：SVG 站位图 / CAM + FOV
- **不能裁剪任何文字或图像**：截图要覆盖该 `seg-row` 的完整高度和宽度。
- **不能有滚动条、浏览器地址栏、任务栏、水印、选区高亮**。

### 3.2 命名规则

统一格式：

```text
SEG-{两位编号}-故事板参考图.png
```

例如：

- `SEG-01-故事板参考图.png`
- `SEG-02-故事板参考图.png`
- `SEG-12-故事板参考图.png`

如果同一 SEG 因内容过长需要拆成上下两张截图，则命名：

```text
SEG-{两位编号}-故事板参考图-上.png
SEG-{两位编号}-故事板参考图-下.png
```

> 一般要求每 SEG 在一屏内排完；如因镜头数过多超出，优先在 HTML 制作阶段拆分 SEG，而不是依赖截图拼接。

### 3.3 图片规格

- 格式：`PNG`（无损、无压缩 artifacts）。
- 分辨率：不低于 HTML 总表在桌面浏览器 1920×1080 下渲染的实际尺寸。
- 比例/尺寸：保持与 HTML 行实际宽高一致，不要拉伸或压缩。
- 背景：保留 HTML 自身背景（通常为 `#fff` 或 `#fafafa`），不要替换为透明。

---

## 4. 推荐截图方法

### 4.1 自动化脚本（推荐）

使用 Playwright 对 HTML 总表做无头截图。脚本位置：

```text
scripts/capture_storyboard_refs.py
```

用法：

```bash
python scripts/capture_storyboard_refs.py path/to/episode_director_full_table.html --output-dir 故事板参考图
```

脚本会自动：

1. 用 Chromium 打开 HTML。
2. 查找所有 `.seg-row`。
3. 逐个滚动到视口并截图。
4. 按 `SEG-XX-故事板参考图.png` 命名保存。

首次使用前需要安装依赖：

```bash
pip install playwright
playwright install chromium
```

### 4.2 手动方式（备用）

如果无法运行脚本：

1. 在浏览器中打开 HTML，窗口最大化（建议 1920×1080 以上）。
2. 关闭所有浏览器插件、书签栏、开发者工具。
3. 按 `Ctrl + Shift + S`（Windows）或浏览器自带截图工具，选择「截取完整页面」后再用图像工具裁剪出单个 `seg-row`。
4. 每裁剪一张后检查：三栏完整、文字清晰、无滚动条。

---

## 5. QA 检查项

交付前逐张核对：

- [ ] 文件夹命名为 `故事板参考图`，不是其他名字。
- [ ] 文件名符合 `SEG-XX-故事板参考图.png` 格式。
- [ ] 每张图只包含一个 `seg-row`。
- [ ] 左、中、右三栏都完整显示，没有裁剪。
- [ ] 中栏文字（镜头号、景别、首/尾帧锚点、台词）清晰可读。
- [ ] 右栏 SVG 站位图没有溢出或错位。
- [ ] 图片没有滚动条、浏览器控件、水印或选区。
- [ ] 编号连续，没有遗漏 SEG。
