# 全局风格规范.md

> 这是 Minimax Storyboard Skill 的通用规则与示例库，不是具体故事项目的风格成品。项目执行时请复制 `templates/project_global_style.md`，填写后保存为项目目录下的 `references/全局风格.md`。
## 一、总则
### 1.1 文件定位
本规范为全项目**最高优先级的美术基准文件**，优先于所有空间锚点、参考图与生成规则。
所有场景、道具、人物、分镜的画面生成，必须严格遵循本规范的风格约束，从根源解决跨场景画风割裂问题。本规范独立于空间体系，连片封闭场景（模式A）与离散序列场景（模式B）通用。

### 1.2 核心目标
1. 锁定全片统一的美术基底与视觉语言，保证整体风格辨识度一致。
2. 支持按剧情段落、场景单元进行风格微调，适配不同情绪与叙事需求。
3. 明确风格统一边界与微调权限，避免单场景风格失控、与整体割裂。

### 1.3 适用范围
覆盖项目内所有视觉产出：场景锚点图、单元布局图、子场景成品图、道具资产图、人物设定图、导演分镜图。

以下为全片必须严格统一的底层风格参数，任何场景、任何镜头均不得突破。

- 主风格品类：[如：AI风格化3D动画 / 赛博朋克写实 / 日系手绘插画 / 复古水彩]

- 统一美术元素：[如：统一的线条粗细 / 统一的明暗过渡方式 / 统一的特效表现形式]

## 三、全局通用风格参数（全片统一维度）
### 3.1 光影体系
- 统一布光逻辑：[如：自然光为主、辅以环境补光 / 戏剧化侧光主照明]
- 统一光影软硬：[如：柔和漫反射光影 / 硬朗直射光影]
- 统一阴影属性：[如：低对比度软阴影 / 高对比度硬阴影]

### 3.2 色彩体系
- 统一色域基调：[如：低饱和莫兰迪色系 / 高对比浓郁色系 / 冷灰调基底]
- 统一色彩逻辑：[如：固有色为主、环境色影响弱 / 强环境色统一色调]
- 统一对比度与曝光：[如：中灰调正常曝光 / 高对比暗调曝光]

### 3.3 材质与质感
- 统一材质表现：[如：哑光质感为主 / 高光金属质感为主]
- 统一画面肌理：[如：轻微胶片颗粒 / 纯净无颗粒 / 手绘纸纹质感]

## 四、分场景风格适配规则（同基底内微调）
### 4.1 适配原则
单场景可根据剧情情绪进行风格微调，必须遵循「**同基底、有差异、不割裂**」原则：
- ✅ 可微调维度：色调冷暖、光影类型、明暗强度、氛围质感、色彩饱和度等氛围层面参数
- ❌ 不可调整维度：美术基底、渲染类型、画面精度、核心视觉语言等全局强制项

### 4.4 自定义使用规则
1. 上表仅为风格参考库，不做强制约束，具体使用方案可根据剧情需求自行选择、组合、修改。
2. 支持新增自定义场景与风格配置，只要不突破全局核心风格基准即可生效。
3. 同一场景可根据剧情节点设置多套风格变体（如白天/夜晚、晴天/雨天），按需调用。
4. 分镜特写、空镜等特殊镜头，可在对应场景风格基础上进一步微调光影与氛围，服务叙事表达。

## 五、风格适配边界与冲突防控规则

### 5.1 相邻场景冷暖跳变控制
相邻两个场景的「色调偏向」不得直接从「暖调系」（暖调复古、暖橙温馨、明媚鲜活等）跳到「冷调系」（冷灰疏离、冷调清冷、青蓝治愈等），中间必须存在过渡场景、桥接元素或明确的剧情转折说明。

### 5.2 饱和度升级需降级使用
「高饱和鲜活」等强饱和度选项仅允许出现在场景的局部焦点元素（如天空、海水、花卉、关键道具），人物、建筑、地面、墙面等画面主体必须保持中低饱和，避免整帧高饱和导致与全局莫兰迪基底割裂。

### 5.3 明暗强度禁止连续极端
「低暗暗调」「昏暗压抑」类场景不得连续出现超过 1 场。若剧情需要连续压抑氛围，必须在中段插入至少一个「柔和适中」或「明亮通透」的喘息场景/镜头，防止视觉疲劳和画风失重。

### 5.4 光影类型必须兼容自然光基底
所有场景的光影类型必须与「自然光为主、辅以环境补光」的全局基底兼容。「单点氛围光」等非常规光影必须标注光源来源（如洞口自然光、窗外路灯、篝火），禁止无来源的戏剧性人工光。

### 5.5 三维同时跳变强制复核
当相邻两场在「色调大类 + 明暗强度 + 色彩饱和度」三个维度中同时变化 ≥2 个时，必须填写「过渡理由」。未提供合理过渡理由的，视为风格冲突，需调整后再进入下一环节。

### 5.6 情绪弧线一致性
场景风格序列应形成可解释的情绪曲线（例如：温暖→渐冷→低谷→回升→温暖），避免无叙事意义的冷暖/明暗震荡。

## 六、调用与执行规则
1. **优先级规则**：本规范优先级高于所有图像参考图的风格影响；当参考图风格与本规范冲突时，以本规范为准。
2. **强制引用规则**：所有画面生成的提示词开头，必须明确引用本规范的「全局核心风格基准」；单场景需额外对应该场景的「风格适配条目」。
3. **微调边界规则**：单场景风格调整仅可在适配维度内进行，严禁修改美术基底、渲染类型等全局强制项。
4. **跨品类通用规则**：道具、人物、分镜的风格生成，均需匹配所属场景的风格微调方向，保证同镜头内元素风格统一。
