# 导演分镜连续制作行为规范
## 一、规范总则
### 1.1 核心目标与定位
本规范是 `references/storyboard-workflow.md` 剧本到分镜工作流中「同一场景连续分镜」环节的专项执行规则，解决同一场景连续分镜制作中「场景参考僵化、机位透视错位、人物-空间关系失配、画面违和」的核心问题，在保障人物形象、环境风格、叙事逻辑统一的前提下，适配不同景别与机位的叙事需求，从规则层面避免全部分镜生硬套用同一张场景图。

### 1.2 适用范围
适用于**同一场景内的多镜头连续导演分镜**制作，支持人物参考图、基准场景图、历史分镜图三类参考资产的组合调用；跨场景跳转、单镜头独立制作可参考本规范的部分通用规则。

---

## 二、参考资产权责与调用规范
所有参考资产严格遵循「权责边界清晰、按需启用、权重分级」原则，禁止无差别全量带入、强绑定画面输出。

### 2.1 人物参考图
- **启用前提**：全部分镜通用，无前置条件
- **核心作用**：锁定人物的面部特征、体型、服饰、发型等核心形象，保障全部分镜人物视觉一致性
- **使用规则**：全程高权重带入，无需二次处理，作为人物形象的唯一基准
- **使用红线**：不得因人物参考约束场景构图、机位与空间布局

### 2.2 基准场景图
- **启用前提**：同一场景内全部分镜通用，作为空间基准锚点
- **核心作用**：锚定场景的空间结构、陈设布局、材质风格、光影基调、色彩体系，是空间合理性的底层依据
- **使用规则**：根据镜头景别与机位偏移程度动态调整参考权重，禁止所有分镜统一强参考
- **使用红线**：不是直接套用的画面模板，禁止无差别裁剪原图充当背景，禁止强制所有镜头沿用相同视角与取景范围

### 2.3 前序 panel

> 术语说明：本节所称「前序 panel」，指同一场景内当前 shot 之前已经生成的、能够提供所需连续信息的彩色分镜图。在阶段 D 单镜头分镜图流程中对应 `panels/` 目录下的某张已生成图；在脚本/配置字段中常对应 `prev_frame_urls`、`previous-frame reference` 或 `previous panel reference`。
>
> 不一定是紧邻的前序 panel。当紧邻的前序 panel 为特写/插入镜头、信息不完整时，可按 2.5 节回退到更早的完整 panel。

- **启用前提**：
  1. 当前 shot 与引用的前序 panel 属于**同一场景**（`Shot List` 中 `Scene` 字段相同，或场景名称/地点一致）。
  2. 当前 shot 不是首镜，且无场景切换/空间重置标记。
  3. **前序 panel 必须已经生成并上传 OSS，其 public URL 已确认可访问。** 未上传完成的前序 panel 不得作为参考图传入。
- **核心作用**：保障前后分镜中人物状态、相对站位、动作衔接、叙事逻辑、美术风格与场景空间氛围的连续连贯，避免人物形象、动作、位置、画风出现前后断裂
- **使用规则**：
  1. 可继承信息：人物外形、服饰、动作姿态、人物间相对位置关系，场景空间关系与光线表现风格，以及美术风格表现（渲染质感、笔触风格、色调处理方式、明暗对比风格）
  2. 参考权重设为中低权重，仅作衔接与风格约束，不主导当前分镜的机位角度、取景范围、画面构图与景别变化
- **使用红线**：
  1. 不得约束机位角度、取景范围、画面构图与景别变化。
  2. 场景透视与光线逻辑主要由基准场景图与全局风格决定；前序 panel 仅作为辅助风格参考，不能替代场景参考图的空间基准作用。

### 2.4 参考图调用通用声明要求

> **本节要求的五项声明是流程控制信息，应写入场景状态备忘或 agent 工作记录，供生成前校验使用；不得写入给生图模型的 prompt。** 给生图模型的 prompt 只应包含画面事实、风格约束和必要的连续性动作描述。

**每次调用任何参考图（人物参考图、基准场景图、前序 panel、场景扩展图等）时，都必须在场景状态备忘中说明以下基础信息：**

1. **参考图身份**：这是什么图（例：人物三视图、卧室基准场景图、前序 panel、机位扩展场景图）。
2. **调用目的**：为什么要带这张图（例：锁定人物外貌、保持空间基准、保证动作衔接、扩展新机位视角）。
3. **使用方式**：是强参考、弱参考还是风格锚点（例：高权重锁定人物形象 / 弱参考约束环境风格 / 中低权重仅作人物动作衔接）。
4. **位置说明**：参考图内关键元素在当前画面中应处于什么位置。涉及人物时，必须说明人物在画面中的侧位（screen-left / center / screen-right）与深度层（foreground / midground / background），以及相对于前一张分镜的位置变化或延续关系。
5. **不用于什么**：明确限制参考图不能主导当前画面的哪些方面（例：不约束机位、不约束构图、不直接当背景套用）。

**注意**：本节是通用基础说明要求；当基于父级场景图/布局图生成子场景、子活动区或同场景新机位图时，还须按 `references/场景锚点.md` 第五部分补充更详细的「4 要素声明」。

#### 前序 panel 声明模板

引用前序 panel 时，场景状态备忘按以下格式书写：

```markdown
- 参考图身份：前序 panel（SH-XXX panel）。
- 调用目的：保持 SH-YYY 与 SH-XXX 之间人物外形、服装、姿态、相对位置、场景空间氛围和美术风格表现的连续。
- 使用方式：中低权重 continuity reference 与风格参考，不主导当前分镜构图。
- 位置说明：SH-XXX 中 [人物A] 位于 [screen-left/center/screen-right] + [foreground/midground/background]；SH-YYY 中 [人物A] 应保持/变化为 [位置]。
- 不用于什么：不约束 SH-YYY 的机位角度、取景范围、画面构图、景别变化；场景透视与光线逻辑以基准场景图和全局风格为准。
```

**该模板内容只写入场景状态备忘，不得复制到给生图模型的 prompt 中。** 生图 prompt 里只需保留画面事实和一句简洁的风格连续指令，例如：

```text
Maintain the same colored storyboard rendering style, texture treatment, and color handling as the previous panel.
```

#### 权重表达方式

生图模型通常不提供独立的参考图权重字段，权重只能通过 prompt 中的措辞和参考图声明来体现。各类型参考图在 prompt 中的权重表达建议：

| 参考图类型 | prompt 中的权重表达 | 示例措辞 |
|---|---|---|
| 人物三视图 / 服装三视图 | 高权重 | `HIGH-weight reference to preserve faces, hairstyles, and costumes consistently` |
| 基准场景图 | 中权重 | `STYLE ANCHOR ONLY; preserve architectural style, color tone, lighting direction, and material system` |
| 道具图 | 中权重 | `Preserve the appearance of [prop name]` |
| 前序 panel | 低权重 | `LOW-weight continuity reference; maintain the same rendering style and character state, do NOT constrain camera angle or composition` |

注意：具体措辞可根据实际使用的生图 API 调整，但**必须明确写出前序 panel 不约束机位、构图、取景**。

#### 场景状态备忘格式

每生成一张 panel 后，按实际画面更新场景状态备忘，作为下一镜的连续性依据。文件命名为：

```text
doc/场景状态_{scene_id}.md
```

内容格式：

```markdown
# 场景状态：{scene_id}

- 场景名称：{名称}
- 最后更新 shot：{SH-XXX}
- 在场人物及位置：
  - {人物A}：{screen-left/center/screen-right} + {foreground/midground/background}，{姿态/动作/表情}
  - {人物B}：...
- 关键道具状态：{道具名}：{归属/手别/位置/朝向}
- 上一动作终点：{描述}
- 光线基调：{描述}
```

生成下一张分镜前，必须读取并延续该备忘。

#### 失败重试策略

单张 panel 生成失败时：

1. **第一次失败**：保持 prompt 和参考图不变，直接重试 1 次。
2. **第二次失败**：保持核心画面要求不变，微调 prompt 措辞（如调整随机性、补充否定词、细化位置描述），重试 1 次。
3. **第三次失败**：停止该场景剩余 panel 的生成，向用户汇报失败镜头、失败原因和已生成结果，等待进一步指示。

禁止静默跳过失败镜头，禁止无限重试。

### 2.5 前序 panel 调用判断引导
是否启用前序 panel 作为衔接参考，不由「相邻」单一条件决定，而由该图是否包含当前镜头所需的连续信息决定。生成前执行以下判断：

1. **信息完整判断**
   - 列出当前镜头必须保持连续的信息：在场人物、关键道具状态、人物相对位置、身体朝向、视线方向、空间关系。
2. **参考图适配判断**
   - 若前序 panel 为全景/中景，且完整包含当前场景全部关键人物与所需空间关系，可直接作为衔接参考。
   - 若前序 panel 为特写/近景，仅展示部分人物或局部动作，则该图**仅继承被摄主体的表情、动作、姿态、服装细节**，不得继承空间构图、人物在场关系、相对站位。
   - 若前序 panel 与当前分镜在景别、机位上发生大幅跳跃（如远景切特写），优先保证场景基准图一致，人物动作衔接退化为弱约束。
3. **组合引用策略**
   - 当前序 panel 无法完整承载连续性时，采用「主参考 + 补充参考」组合：
     - **空间/全员在场主参考**：回退引用同场景内最近一张包含完整空间与人物的基准场景图，或该机位专属场景扩展图。
     - **人物动作补充参考**：前序 panel（仅用于被拍摄主体的姿态、表情、服装细节）。
     - **人物形象基准参考**：人物三视图/服装三视图（始终高权重）。

## 三、镜头分级与场景参考动态匹配策略
按景别大小、机位偏移程度，将同一场景内的分镜划分为3个等级，对应差异化的基准场景图调用策略，从根源避免「一图到底」违和感。

### 3.1 一级镜头：全景/固定机位镜头
- **镜头特征**：机位、视角与基准场景图基本一致，以展示完整空间、人物全局站位、整体环境氛围为主（例：三人在厨房吃饭的全景）
- **场景参考策略**：基准场景图设为**强参考**，严格匹配空间布局、光影走向、陈设位置与整体透视

### 3.2 二级镜头：中景/小范围机位平移
- **镜头特征**：景别缩小，机位小范围平移/微调，画面主体为人物互动，取景范围仍在基准场景图的视野覆盖内（例：聚焦餐桌两人对话的中景、人物半身镜头）
- **场景参考策略**：基准场景图设为**弱参考**，仅约束环境风格、材质、色调与光影逻辑；透视、画面构图、可见元素跟随镜头自然调整，禁止强行裁剪原图充当背景

### 3.3 三级镜头：特写/大机位变动/局部动作镜头
- **镜头特征**：景别为特写/近景，机位大幅推拉摇移，画面主体为人物动作、局部道具，基准场景图的原视野无法覆盖（例：人物添饭的手部特写、转身走向冰箱的跟拍镜头、灶台区域近景）
- **场景参考策略**：基准场景图仅作**风格锚点**，禁止直接作为背景套用；必须先执行「场景扩展流程」，生成对应机位的专属场景图，再以该机位专属场景图作为场景参考生成最终分镜

## 四、分镜生成前置校验机制
每一张分镜生成前，必须完成以下4项校验，校验通过后方可匹配对应策略执行生成，禁止跳过判断直接调用参考图。

### 4.1 动作空间校验
判断当前分镜的人物动作、站位，是否仍在基准场景图的可见区域内；若人物/核心道具已移出原基准图视野，判定为三级镜头，触发场景扩展流程。

### 4.2 机位匹配校验
判断当前镜头的景别、机位角度、透视关系，是否与基准场景图的视角匹配；若偏差过大，禁止强套用原场景图，按镜头分级下调参考权重或触发场景扩展。

### 4.3 元素可见性校验
判断当前镜头中，哪些场景元素应当出现、哪些应当移出画面（例：添饭特写中，电饭煲应在画面内，远处的冰箱应移出画面），严格控制画面元素的空间合理性，禁止强制保留基准图全部陈设。

### 4.4 风格跨度校验
判断当前分镜所属场景的风格适配条目，与上一分镜所属场景是否构成「三维同时跳变」（色调大类、明暗强度、色彩饱和度同时变化 ≥2 个）。若构成冲突：
1. 优先通过局部元素调整解决（如限定高饱和仅用于背景、补充桥接光源等），而非直接套用风格提示词；
2. 无法通过局部调整解决时，返回场景风格配置阶段重新协商，禁止无过渡直接生成。

---

## 五、场景扩展与重制执行规则
当判定为三级镜头、或校验后确认原场景图无法匹配当前镜头时，必须执行场景扩展流程，而非生硬复用原图。

1. **扩展基准**：必须以原基准场景图为唯一空间基准，保持材质、光影、陈设风格、空间尺度、色彩体系100%统一
2. **扩展逻辑**：基于当前镜头的机位、视角、取景范围，推演对应视角下的场景画面，补充原基准图视野外的空间内容，保证空间结构自洽
3. **扩展产物**：生成该镜头专属的「机位匹配场景图」，作为当前分镜的场景参考，替代原基准场景图的强参考作用
4. **复用规则**：同机位的后续分镜可复用该机位匹配场景图；机位再次发生显著变化时，需重新执行场景扩展

## 六、连续分镜连贯性保障规则
1. **空间坐标统一**：同一场景所有分镜共享同一套空间坐标系，人物移动、机位变化必须符合真实空间逻辑，不得出现人物瞬移、陈设位置前后矛盾
2. **动作衔接连续**：每一张新分镜，必须以上一分镜的人物位置、动作为起点，走位、动作过渡自然合理
3. **风格统一底线**：无论机位如何变化、场景是否扩展，整体光影色调、美术风格、材质质感必须与基准场景图保持完全一致
4. **场景状态文本备忘**：同一场景连续分镜必须维护一份轻量级文本状态说明，用于补全图像参考无法传递的信息：
   - 当前场景名称与空间锚点
   - 在场人物及其相对位置、身体朝向、视线方向
   - 关键道具的状态与归属
   - 上一分镜结束时的动作终点
   - 生成下一张分镜前，将该备忘与参考图一起作为输入，防止模型因前序为特写而误判「某人不在场」或空间关系丢失
   - 每生成一张分镜后，按实际画面更新备忘，作为下一镜的连续性依据

---

## 七、标准执行流程（Agent固定执行步骤）
1. **需求拆解**：接收分镜脚本，逐个拆解每个镜头的景别、机位、人物动作、核心叙事点与所属场景
2. **资产匹配校验**：
   - 通用必带资产：载入人物参考图、基准场景图、当前场景状态文本备忘
   - 衔接类资产判断：判断是否满足「同一场景 + 连续相邻分镜」双条件，并按 2.5 节判断前序 panel 是否适配当前镜头需求，决定是否启用、降级为弱参考或回退到更早的完整场景图
3. **镜头分级判定**：执行「人物-空间-风格四项校验」，根据校验结果判定当前镜头等级，匹配对应的场景参考调用策略
4. **场景扩展执行（按需触发）**：若判定为三级镜头，先基于基准场景图生成对应机位的专属场景图，替换原场景参考
5. **分镜生成执行**：按对应权重带入所有合规参考资产与场景状态备忘，执行分镜画面生成。同一场景内无依赖的镜头可并行生成；依赖前序 panel 的镜头必须串行，并在前序 panel 上传获得 public URL 后再启动
6. **成品校验输出**：校验空间合理性、叙事连贯性、风格统一性，确认无误后输出分镜成品
7. **场景状态备忘更新**：按实际生成分镜更新当前场景状态文本备忘（在场人物、位置、道具、动作终点），作为下一分镜的连续性依据
本流程输出（锁定后的镜头、人物状态、机位与场景参考）作为 `references/storyboard-sketch.md` 彩色分镜图 brief 的输入依据。
