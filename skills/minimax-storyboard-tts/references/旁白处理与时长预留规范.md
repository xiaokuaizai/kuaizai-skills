# TTS 音色样本与正式文本时长边界

> 本规范只定义 `/minimax-storyboard-tts` 的职责边界。人物与旁白的 TTS 输出都是试听/音色参考样本，不是正式台词音轨。

## 1. 统一音频逻辑

1. 从剧本识别人物对白和旁白角色，为每个声音身份推荐音色。
2. TTS 生成主选和备选试听样本，样本文本可取该角色的代表性原句。
3. 人工确认后的样本上传为 `tts_reference`，供 Minimax H3 模仿音色、语速或气质。
4. 人物对白和旁白的正式内容都由 `/minimax-storyboard` 写入 prompt，再由 Minimax H3 生成。
5. 不生成 `tts_production`，不生成逐句正式人物/旁白音轨，也不通过 FFmpeg 后期叠加旁白。

## 2. 样本时长

- 试听样本目标为自然完整且不超过 7-8 秒。
- 快速估算可使用：英文每词约 0.4 秒，中文每字约 0.22 秒。
- 该估算仅用于挑选试听文本，不代表 Minimax H3 正式台词的最终时长。
- 样本太长时在完整句或语义断点截取；不要为了凑时长破坏语义。

## 3. 转为 reference_audio

人工确认某个样本后，将其登记为 `tts_reference`。提交到单个 SEG 前由 `/minimax-story-package` 检查：

- 格式为 mp3/wav；
- 最多 3 段；
- 每段 2-15 秒；
- 总时长不超过 15 秒；
- 每段都有可访问的 public URL。

reference_audio 不需要与正式台词逐字一致，也不需要和 SEG 或时间轴一一对应。资产包中必须标记：

```json
{
  "purpose": "voice_only",
  "content_binding": false
}
```

## 4. 与 storyboard 的分工

| 工作 | 负责 skill | 校验对象 |
|---|---|---|
| 识别人物与旁白声音身份 | `minimax-storyboard-tts` | 角色清单 |
| 推荐音色、生成试听样本 | `minimax-storyboard-tts` | 样本自然度与试听长度 |
| 上传已确认音色参考 | `minimax-story-package` | 格式、实际时长、URL |
| 估算正式对白/旁白时长 | `minimax-storyboard` | prompt 中的正式文本 |
| 拆分 Shot/SEG、编写声音时间轴 | `minimax-storyboard` | 正式文本完整性与 15 秒上限 |
| 生成正式人物对白和旁白 | Minimax H3 | prompt 时间轴 |

## 5. 禁止项

- 禁止把试听样本或参考样本称为“正式音频”。
- 禁止要求参考样本与正式台词时长误差保持在某个范围内。
- 禁止按 SEG 批量生产 TTS 正式台词。
- 禁止因参考样本内容不同而判定失败。
