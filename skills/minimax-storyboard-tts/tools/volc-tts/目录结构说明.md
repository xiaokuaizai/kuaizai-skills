# TTS 目录结构说明

更新时间：2026-07-27

本文说明 `G:\draw_long\novel\对口型\TTS` 的目录用途。后续第一章到第七章的 TTS 文件，统一优先放在 `output/chapterN/` 下面。

## 根目录

| 路径 | 用途 | 说明 |
|---|---|---|
| `data/` | 台词数据 | 存放 `chapter1_lines.json`、`chapter2_lines.json`、`chapter3_lines.json` 这类结构化台词源数据。 |
| `doc/` | 文档资料 | 存放音色列表、接口说明、流程说明等辅助文档。 |
| `src/` | 公共代码 | 存放 TTS 配置、通用客户端等可复用代码。 |
| `output/` | 生成结果 | 存放各章节 TTS 音频、字幕、清单和导出结果。 |
| `tools/` | 后续工具脚本预留 | 后续如要整理新工具脚本，可放这里。当前未搬动旧脚本，避免影响已有调用。 |
| `logs/` | 运行日志预留 | 后续批量生成时，可把运行记录或错误日志放这里。 |
| `archive/` | 归档预留 | 旧脚本、旧输出、废弃实验文件确认无用后再移入这里。 |
| `node_modules/` | Node 依赖 | 由 npm 安装生成，不手动编辑。 |
| `__pycache__/` | Python 缓存 | Python 自动生成，可忽略。 |

每个章节目录统一包含：

| 子目录 | 用途 |
|---|---|
| `audio/` | 当前章节逐句 mp3 音频。 |
| `subtitles/` | 当前章节 SRT 或其他字幕文件。 |
| `manifests/` | 当前章节生成清单、校验结果、时长统计等。 |
| `tasks/` | 当前章节 TTS 任务清单、人工核对表等。 |
| `exports/` | 合并音频、交付包、给剪辑使用的导出文件。 |
| `tmp/` | 临时文件，确认无用后可清理。 |

## 放置规则

1. 新章节 TTS 主输出统一放到 `output/chapterN/`。
2. 逐句音频放 `audio/`，字幕放 `subtitles/`，任务清单放 `tasks/` 或章节根目录。
3. 清单文件建议同时保留机器可读 JSON 和人工可读 Markdown。
4. 旧输出不要直接删除；确认不用后再移入 `archive/old_outputs/`。
5. 旧脚本不要直接删除；确认不用后再移入 `archive/legacy_scripts/`。
6. 第三章后续同步以 `sync_chapter3_tts.py` 为入口，输出目录已经统一为 `output/chapter3/`。
