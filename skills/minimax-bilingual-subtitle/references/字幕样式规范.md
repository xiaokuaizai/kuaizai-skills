# 字幕样式规范

## 默认样式

| 属性 | 英文 | 中文 |
|---|---|---|
| 字号 | 36 px | 26 px |
| 字体 | FangSong（仿宋） | FangSong（仿宋） |
| 颜色 | 白色 `&H00FFFFFF` | 白色 `&H00FFFFFF` |
| 描边 | 黑色 2 px | 黑色 2 px |
| 阴影 | 1 px | 1 px |
| MarginV（底部边距） | 72 | 24 |
| 对齐方式 | 2（底部居中） | 2（底部居中） |

整体效果：
```
[视频画面]

   English line 1
   English line 2

   中文行
```

## 字号调整经验

支线 17 视频分辨率 768×1344（9:16 竖屏）。

| 字号组合 | 效果 |
|---|---|
| 英文 36 / 中文 22 | 中文偏小，显示不完全（用户反馈） |
| 英文 36 / 中文 26 | 合适（当前默认） |

横屏视频（1920×1080）建议：
- 英文 48-54 / 中文 32-36
- MarginV 英文 90 / 中文 30

## ASS 特殊字符

`{` 和 `}` 是 ASS 格式控制符，必须转义：
- `{` → `(`
- `}` → `)`

## Windows 字体路径

系统仿宋字体路径（用于其他工具直接引用）：
- `C:\Windows\Fonts\simfang.ttf`
- `C:\Windows\Fonts\STFANGSO.TTF`

ASS 的 `Fontname` 直接用 `FangSong` 即可（libass 会自动从系统加载）。

## 编码

ASS 文件用 **utf-8-sig**（带 BOM）保存，Windows 播放器（PotPlayer / 迅雷影音）才能正确识别中文。

## 时间格式

ASS 时间格式：`H:MM:SS.cc`（厘秒，1/100 秒）

```python
def fmt_ass_time(sec: float) -> str:
    h = int(sec // 3600)
    m = int((sec % 3600) // 60)
    s = int(sec % 60)
    cs = int(round((sec - int(sec)) * 100))
    return f'{h}:{m:02d}:{s:02d}.{cs:02d}'
```
