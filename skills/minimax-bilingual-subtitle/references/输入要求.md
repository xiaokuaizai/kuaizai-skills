# 输入要求

## 环境准备（首次运行必做）

### 1. Python 依赖

```bash
pip install faster-whisper
```

### 2. Kimi API 环境变量（用于中文翻译）

```powershell
$env:ANTHROPIC_AUTH_TOKEN="sk-kimi-..."
$env:ANTHROPIC_BASE_URL="https://api.kimi.com/coding/"
$env:ANTHROPIC_MODEL="kimi-for-coding"
```

或持久化到系统环境变量。

### 3. whisper 模型（一次性下载，所有项目共享）

```bash
# 在 skill scripts 目录下
python 00_download_whisper_model.py                  # 默认 base（145MB）
python 00_download_whisper_model.py --model small    # 更精准但慢
python 00_download_whisper_model.py --list           # 查看所有可选模型 + 缓存状态
python 00_download_whisper_model.py --force          # 强制重新下载（覆盖缓存）
```

下载源默认 `https://hf-mirror.com`（国内可直连）。

**缓存机制**：
- 缓存位置：`C:\Users\{用户名}\.cache\huggingface\hub\models--Systran--faster-whisper-{模型名}\`
- **系统级缓存**：跟会话、工作区、项目无关，下载一次永久可用
- **跨项目共享**：所有用 faster_whisper 的代码（包括其他 skill）都自动复用
- **不会重复下载**：脚本运行前会先检查缓存，已存在则直接跳过
- 即使新开 Claude 会话、换工作区，只要调用 `02_transcribe_by_seg.py`，faster_whisper 库会自动找到此缓存

模型大小对比：

| 模型 | 大小 | 速度 | 精度 | 推荐场景 |
|---|---|---|---|---|
| tiny | 39 MB | 极快 | 低 | 快速测试 |
| **base** | **145 MB** | **快** | **中** | **默认，支线 17 实测够用** |
| small | 461 MB | 中 | 中高 | 更精准但 CPU 慢 2-3 倍 |
| medium | 1.5 GB | 慢 | 高 | 建议 cuda |
| large-v3 | 2.9 GB | 很慢 | 最高 | 建议 cuda |

### 4. ffmpeg

需要已在 PATH 中：`ffmpeg -version` 能输出版本号即可。

## 中文翻译流程

中文不再依赖中文剧本的 zh_units 配对（容易错位），改用 **Kimi API 直译**：

**1. 调翻译脚本生成 `su_zh.json`（每个 SU fragment → 中文）**

```bash
python scripts/translate_su_with_kimi.py \
  --su-table "F:/path/to/文本语义拆分表.md" \
  --workspace "F:/path/to/工作区"
```

输出：`{workspace}/su_zh.json`，格式 `{frag_id: "中文"}`，如：
```json
{
  "SU-01-N1a": "晨光洒进教室...",
  "SU-01-D1": "早上好，我的朋友，"
}
```

**2. `01_extract_seg_lines.py` 自动从 `su_zh.json` 读中文**

不需要 `--zh-script` 参数（已废弃）。如果 `su_zh.json` 不存在会报错提示先跑翻译脚本。

**3. 翻译特性**：
- 每条 fragment 单独调用 Kimi API，避免长文本不稳定
- 直译（非意译），保留原文语气和标点风格
- 已翻译的 fragment 会跳过（除非 `--force`）
- 每次调用间隔 0.5s，99 条约 8 分钟

## SEG prompt 格式（--format）

minimax-storyboard 有多种 SEG 提示词产物：

| 格式 | 路径 | 说明 |
|---|---|---|
| `shot`（默认） | `doc/minimax_h3_prompts/{SEG}_prompt.md` | 每 SEG 一个文件（17 支线） |
| `seg` | `doc/最终提示词/{SEG}_final_prompt.md` | 每 SEG 一个文件 |
| `shot_dash` | `doc/最终提示词/{SEG}_最终提示词.md` | X.X–Y.Ys: 台词："..."（EN dash） |
| `single` | `doc/H3最终提示词.md` | **所有 SEG 在一个文件**（03 支线） |
| 时间轴+台词分离（06 支线） | `00_元数据/提示词/{SEG}_prompt.txt` | **不在 parser 支持范围**，需预处理成 `shot` 格式 |

**判断方法**：看故事板 `doc/` 下哪个目录/文件存在。若为 06 支线格式（时间轴+台词分离、`.txt` 后缀），按 `references/支线输入预处理.md` 转换。

## SU 拆分表格式

minimax-storyboard 的 `doc/文本语义拆分表.md` 有多种格式：

### 嵌套式（17 支线）

```
- **SU-01a**：`text`
- **SU-01b**：`text`
```

父行通过 `→ SU-01a / SU-01b` 引用子片段，子片段定义在表尾。

### 平铺式 - 10 列（03 支线）

```
| SU ID | 场景 | 类型 | 说话人 | 原始文本 | 词数 | ... | 是否拆分 | 拆分后片段 | 备注 |
| SU-01-N1 | Scene One | narration | — | text | 49 | ... | 是 | SU-01-N1a + SU-01-N1b | ... |
| SU-01-N1a | Scene One | narration | — | text | 32 | ... | 否 | — | 拆分后片段 |
```

特点：
- 命名格式 `SU-XX-N1`（旁白）/ `SU-XX-D1`（对白）
- 子片段作为独立行紧跟父行
- 父行"拆分后片段"列是子片段 ID 列表（`SU-01-N1a + SU-01-N1b`）

### 平铺式 - 8 列（04 支线）

```
| Unit ID | 场景 | 类型 | 说话人 | 原始文本 | 预估时长 | 是否拆分 | 拆分建议 |
| SP-01 | Scene One | Narration | — | text | ~10.3s | 否 | 单句完整 |
| SP-02 | Scene One | Narration | — | text | ~13.0s | **建议拆分** | 拆分点 A：after "loud." |
```

特点：
- 命名格式 `SP-XX`（SP = Semantic Phrase）
- 类型列是 `Narration` / `Dialogue`（首字母大写，非全小写）
- "是否拆分"列是 `否` 或 `**建议拆分**`
- "拆分建议"列是**文字描述**（如"拆分点 A：after 'loud.'"），**不是 frag_id 列表**
- 因此**长字幕不会被预拆**，需要 `force_split_subtitle` 兜底强拆

### 混合式（06 支线）

8 列平铺主表 + 表尾 `### SU-XX 拆分` 4 列子表。

```
| SU-01 | SC-01 | Narration | — | text | 9.5s | 是 | 按句子拆分为 SU-01-A/B/C，用于镜头间分配 |
...
### SU-01 拆分
| 片段 | 原文 | 估算时长 | 拆分理由 |
| SU-01-A | text | 3.5s | 完整句子 |
```

特点：
- 拆分片段定义在表尾的 `### SU-XX 拆分` 子表（不是 `- **SU-XXa**：\`text\`` 列表）
- 子片段 ID 是大写连字符形式（SU-01-A），parser 只认小写无连字符（SU-01a）
- "估算时长"列带 `s` 后缀（9.5s），17 支线嵌套式 parser 的正则 `[\d.]+` 不匹配

**预处理**：转成 17 支线嵌套式（详见 `references/支线输入预处理.md`）

### 兼容性

`parse_su_table` 自动识别以上前三种格式（嵌套式、10 列平铺、8 列平铺），**不识别混合式**（06 支线）需预处理。

SP 表对白列可能含动作描述（`"..." An Qi said, ...`），脚本自动剥离为纯台词。

## minimax-storyboard 二次产物（复用清单）

| 文件 | 用途 |
|---|---|
| `doc/minimax_h3_prompts/SEG-XX_prompt.md` 或 `doc/最终提示词/SEG-XX_final_prompt.md` 或 `doc/H3最终提示词.md` | 提取 SEG 内台词行（含 SEG 内时间戳 + 英文 + 说话人） |

## 无二次产物时

本 skill **依赖** minimax-storyboard 二次产物，没有 SU 拆分表或 SEG prompt 时不能工作。

**建议**：先按 `/minimax-storyboard` 流程跑完拿到二次产物，再用本 skill。
