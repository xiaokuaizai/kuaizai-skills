# 拼接规则

> 本文件规定 `/minimax-ffmpeg-assembly` 使用 FFmpeg 拼接视频的基本规则。

## 工具要求

- FFmpeg 必须已安装并在 PATH 中可用。
- 脚本优先调用 `ffmpeg` 命令，不绑定具体安装路径。

## 拼接方式

统一使用 FFmpeg 的 **concat demuxer** + **stream copy** 方式：

```bash
ffmpeg -y -f concat -safe 0 -i concat_list.txt -c copy output.mp4
```

参数说明：

- `-y`：覆盖已存在文件。
- `-f concat`：使用 concat demuxer。
- `-safe 0`：允许文件路径中包含特殊字符。
- `-i concat_list.txt`：输入文件列表。
- `-c copy`：直接复制流，不重新编码。

## concat list 格式

```text
file 'SEG-01.mp4'
file 'SEG-02.mp4'
file 'SEG-03.mp4'
```

每行一个 `file '路径'`，顺序即拼接顺序。

## 硬切规则

- SEG 之间、Scene 之间均使用硬切，不加淡入淡出、黑场或其他转场。
- 未来如需转场，应新建独立 skill 或在用户明确要求时额外处理。

## 编码一致性检查

使用 `-c copy` 前，必须检查所有输入视频的以下参数是否一致：

| 参数 | 是否必须一致 | 检查方式 |
|---|---|---|
| 分辨率（width x height） | 是 | `ffprobe -v error -select_streams v:0 -show_entries stream=width,height` |
| 视频编码器 | 是 | `ffprobe -v error -select_streams v:0 -show_entries stream=codec_name` |
| 像素格式 | 是 | `ffprobe -v error -select_streams v:0 -show_entries stream=pix_fmt` |
| 帧率 | 是 | `ffprobe -v error -select_streams v:0 -show_entries stream=r_frame_rate` |
| 音频编码器 | 是 | `ffprobe -v error -select_streams a:0 -show_entries stream=codec_name` |
| 音频采样率 | 是 | `ffprobe -v error -select_streams a:0 -show_entries stream=sample_rate` |
| 视频码率 | 否 | 不需要检查，VBR 视频码率不同不影响 `-c copy` |

注意：视频码率（bit_rate）不需要检查。Minimax 返回的 SEG 视频通常是 VBR，码率会波动，但编码参数一致时 `-c copy` 仍可正常拼接。

## 不一致处理

严格模式（默认）：

1. 列出所有不一致的 SEG 和具体差异。
2. 停止当前拼接任务。
3. 建议用户：
   - 重新生成规格不一致的 SEG；或
   - 手动用其他工具转码成统一规格后，再调用本 skill。

本 skill **不自动转码**，避免意外质量损失。

## DTS 警告处理（可选）

使用 `-c copy` 拼接多个独立 mp4 文件时，ffmpeg 可能报 `Non-monotonic DTS` 警告。原因是每个 SEG 的音频时间戳独立，拼接后出现轻微回退。

### 判断标准

- 如果输出视频播放正常，无音频卡顿、爆裂、静音，可忽略该警告。
- 如果播放有音频问题，需要重新编码音频轨道。

### 修复命令

保留视频流不变，只重新编码音频：

```bash
ffmpeg -y -f concat -safe 0 -i concat_list.txt -c:v copy -c:a aac -b:a 128k output.mp4
```

参数说明：

- `-c:v copy`：视频流直接复制，不损失画质。
- `-c:a aac`：音频流重新编码为 AAC。
- `-b:a 128k`：音频码率 128 kbps。

重新编码音频后，DTS 警告会消失，但拼接时间会略微增加。

## 时长校验

拼接完成后，必须校验输出视频时长是否约等于输入视频时长之和：

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 output.mp4
```

允许误差：±0.2 秒。超出误差范围视为校验失败。
