# 产物管理规范

> 本文件规定 `/minimax-ffmpeg-assembly` 产物的保存路径、命名规则和登记表格式。

## 产物目录结构

```text
04_支线产出/
└── 产出/
    └── {branch}/
        ├── 分段视频/                    # 上游输入（minimax-video-dispatch 产物）
        │   ├── SEG-01/
        │   │   └── SEG-01.mp4
        │   └── ...
        ├── 场次视频/                    # 本 skill 输出
        │   ├── Scene-01.mp4
        │   ├── Scene-02.mp4
        │   └── ...
        └── 完整视频/                    # 本 skill 输出
            └── {branch}_完整版.mp4
```

## 产物命名

| 产物 | 命名格式 | 示例 |
|---|---|---|
| Scene 视频 | `Scene-XX.mp4` | `Scene-01.mp4` |
| 完整支线视频 | `{branch}_完整版.mp4` | `支线1_完整版.mp4` |
| 旧版归档 | `{原文件名}_旧版v{N}.mp4` | `Scene-01_旧版v1.mp4` |

## 登记表

维护一份 `00_元数据/清单/scene_assembly_log.json`，记录每次拼接结果：

```json
{
  "project": "英语项目",
  "branch": "支线1",
  "assembled_at": "2026-08-27T12:00:00",
  "scenes": [
    {
      "scene_id": "Scene-01",
      "segment_ids": ["SEG-01", "SEG-02"],
      "output_path": "04_支线产出/产出/支线1/场次视频/Scene-01.mp4",
      "duration": 10.0,
      "status": "succeeded"
    }
  ],
  "full_video": {
    "output_path": "04_支线产出/产出/支线1/完整视频/支线1_完整版.mp4",
    "duration": 60.0,
    "status": "succeeded"
  }
}
```

## 旧版归档

覆盖已存在的 Scene 视频或完整视频前：

1. 把旧版移动到同目录 `旧版/` 文件夹。
2. 命名：`{原文件名}_旧版v{N}.mp4`。
3. 在 `旧版/说明.txt` 中记录归档时间、原因、新旧文件名。

## 与 `/minimax-story-package` 的衔接

本 skill 只负责本地拼接。拼接产物需等用户确认后，再调用 `/minimax-story-package` 上传 OSS：

```bash
python .claude/skills/minimax-story-package/scripts/register_outputs.py \
  --project 英语项目 \
  --branch 支线1 \
  --asset-type output_full_video \
  --files "04_支线产出/产出/支线1/完整视频/支线1_完整版.mp4" \
  --upload
```

## QA 检查项

- [ ] 所有 SEG 视频已存在且状态为 succeeded。
- [ ] 编码一致性检查通过，或已停止并向用户报告。
- [ ] 每个 Scene 视频时长等于对应 SEG 时长之和。
- [ ] 完整视频时长等于所有 SEG 时长之和。
- [ ] `scene_assembly_log.json` 已更新。
- [ ] `doc/文件地址管理.md` 已登记产物路径。
- [ ] 用户确认后，已调用 `/minimax-story-package` 上传。
