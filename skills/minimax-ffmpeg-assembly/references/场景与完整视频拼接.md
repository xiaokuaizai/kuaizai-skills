# 场景与完整视频拼接

> 本文件说明如何按 Scene 拼接 SEG 视频，以及如何拼完整支线视频。

## 输入映射

从 `doc/视频分段.md` 中读取 SEG 与 Scene 的对应关系：

```markdown
| SEG ID | Scene | Duration | ... |
|---|---|---|---|
| SEG-01 | Scene-01 | 5 | ... |
| SEG-02 | Scene-01 | 5 | ... |
| SEG-03 | Scene-02 | 6 | ... |
```

建立映射：

```python
scene_map = {
    "Scene-01": ["SEG-01", "SEG-02"],
    "Scene-02": ["SEG-03"],
}
```

## 按 Scene 拼接

对每个 Scene：

1. 按 SEG 编号顺序排序。
2. 生成 concat list：`Scene-XX_concat.txt`。
3. 调用 ffmpeg 输出 `04_支线产出/产出/{branch}/场次视频/Scene-XX.mp4`。
4. 校验输出时长。

示例：

```bash
ffmpeg -y -f concat -safe 0 -i Scene-01_concat.txt -c copy Scene-01.mp4
```

## 完整支线视频拼接

所有 Scene 视频生成后：

1. 按 Scene 编号顺序排序（Scene-01, Scene-02, ...）。
2. 生成 concat list：`branch_concat.txt`。
3. 调用 ffmpeg 输出 `04_支线产出/产出/{branch}/完整视频/{branch}_完整版.mp4`。
4. 校验输出时长是否等于所有 SEG 时长之和。

示例：

```bash
ffmpeg -y -f concat -safe 0 -i branch_concat.txt -c copy 支线1_完整版.mp4
```

## 顺序规则

- SEG 顺序：按 SEG 编号中的数字部分排序（SEG-01, SEG-02, ..., SEG-10, ...）。
- Scene 顺序：按 Scene 编号中的数字部分排序（Scene-01, Scene-02, ...）。
- 不允许用户手动调整顺序，顺序必须以 `doc/视频分段.md` 为准。

## 单 SEG 场景

如果某个 Scene 只包含一个 SEG，直接复制该 SEG 视频到 `场次视频/` 目录，不重新编码。

## 失败处理

- 如果某个 Scene 中任意 SEG 缺失或失败，跳过该 Scene，记录到失败列表。
- 完整支线拼接必须在所有 Scene 视频都成功生成后进行。
- 任意 Scene 失败时，禁止开始完整支线拼接。
