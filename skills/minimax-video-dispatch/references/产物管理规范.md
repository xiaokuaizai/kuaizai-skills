# 产物管理规范

> 本文件规定视频生成产物的保存路径、命名规则、登记表格式和归档规则。

## 产物目录结构

视频生成完成后，产物统一保存到 `04_支线产出/产出/{branch}/分段视频/{segment}/`：

```text
04_支线产出/
└── 产出/
    └── {branch}/
        ├── 完整视频/
        └── 分段视频/
            ├── SEG-01/
            │   ├── SEG-01.mp4              # SEG 完整视频
            │   └── 镜头视频/                # 按需拆分后的镜头视频
            │       ├── SH-01.mp4
            │       └── SH-02.mp4
            ├── SEG-02/
            └── ...
```

## 产物登记表

每个任务维护一份：

```text
00_元数据/清单/video_generation_log.json
```

模板见 `templates/video_generation_log_template.json`。

## 命名规则

| 产物 | 命名格式 | 示例 |
|---|---|---|
| SEG 完整视频 | `{segment_id}.mp4` | `SEG-01.mp4` |
| 镜头拆分视频 | `{shot_id}.mp4` | `SH-01.mp4` |
| 旧版归档 | `{原文件名}_旧版v{N}.mp4` | `SEG-01_旧版v1.mp4` |

## 下载规则

1. 任务状态变为 `succeeded` 后，立即从 `content.url` 下载视频。
2. 下载链接有时效，禁止只保存 URL 不下载。
3. 下载后校验文件大小非零、可正常播放（可选调用 ffprobe）。
4. 下载失败时重试 3 次，仍失败则标记为 `download_failed` 并向用户汇报。

## 归档规则

1. 覆盖已存在的 `SEG-XX.mp4` 前，先把旧版移动到同目录 `旧版/` 文件夹。
2. 旧版命名：`{原文件名}_旧版v{N}.mp4`，版本号从 1 递增。
3. 在 `旧版/说明.txt` 中记录归档时间、原因、新旧文件名。

## 与 `/minimax-story-package` 的衔接

本 skill 只规定本地产物路径和命名。视频下载到本地后，必须调用 `/minimax-story-package` 完成后续资产管理：

1. 上传 OSS：`/minimax-story-package/scripts/register_outputs.py --asset-type output_segment_video`
2. 更新 `asset_manifest.json`
3. 登记 `doc/文件地址管理.md`
4. OSS 目录规范见 `/minimax-story-package/references/oss目录结构规范.md`

示例：

```bash
python .claude/skills/minimax-story-package/scripts/register_outputs.py \
  --project 英语项目 \
  --branch 支线1 \
  --asset-type output_segment_video \
  --files "04_支线产出/产出/支线1/分段视频/SEG-01/SEG-01.mp4" \
  --upload
```
