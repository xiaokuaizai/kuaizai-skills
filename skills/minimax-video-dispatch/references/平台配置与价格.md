# 平台配置与价格

> 本文件记录 Minimax 官方与秘塔中转站的配置和价格。
> 每次启动 `/minimax-video-dispatch` 时，agent 应询问用户是否需要重新查询官方价格并更新本文件。

## 平台配置

| 平台 | Base URL | API Key 环境变量名 |
|---|---|---|
| Minimax 官方 | `https://api.minimaxi.com` | `MINIMAX_OFFICIAL_API_KEY` |
| 秘塔中转站 | `https://metaso.cn/api/minimax` | `METASO_API_KEY_*`（见下方多 key 说明） |

## 秘塔中转站多 API Key 管理

- 用户可能提供**多个**秘塔 API Key（例如 `METASO_API_KEY_1`、`METASO_API_KEY_2`）。
- 每次启动 skill 时，**必须向用户确认本次使用哪一个 key**。
- **每个 key 的并发上限为 4**：同一时刻最多只能有 4 个任务使用同一个 key 提交或查询。
- 多 key 之间互相独立，key A 的并发耗尽不影响 key B。
- **严格禁止自动切换 key**：脚本只能使用用户明确选定的 key；遇到 429、余额不足或 key 失效时，必须暂停并通知用户，由用户决定是否换 key 或等待，绝不允许脚本私自切换到其他 key。
- 建议 `.env` 中按如下格式配置：

```text
METASO_API_KEY_1=mk-xxxxxxxx
METASO_API_KEY_2=mk-yyyyyyyy
METASO_API_KEY_3=mk-zzzzzzzz
```

如果只有 1 个 key，可继续使用 `METASO_API_KEY` 作为默认变量名。

## 输入素材价格

| 素材类型 | Minimax 官方 | 秘塔中转站 |
|---|---|---|
| 参考音频 | 免费 | 免费 |
| 参考图片 | 前 5 张免费，之后 $0.04 / 张 | 前 5 张免费，之后 0.05 元 / 张 |
| 参考视频（2K 输出） | 按输入时长 × 输出分辨率费率 | 0.15 元 / 秒 |
| 参考视频（768P 输出） | 按输入时长 × 输出分辨率费率 | 0.09 元 / 秒 |
