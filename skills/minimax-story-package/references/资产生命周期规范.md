# 资产生命周期规范

本规范说明一个资产从本地生成到最终进入 OSS 被引用的完整流程。

## 生命周期阶段

```
本地生成 → 路径解析 → 上传 OSS → 获取 public_url → 被生成任务引用 → 产物归档 → 清单更新
```

## 各阶段说明

### 1. 本地生成

由 `/minimax-storyboard` 或 `/minimax-storyboard-tts` 调用本地工具生成：
- 图片：速创APIimage2.0、Playwright 截图等
- 音频：火山引擎 TTS
- 视频：Minimax H3 等

### 2. 路径解析

在调用生成工具前，先调用 `/minimax-story-package` 的 `scripts/resolve_asset_paths.py`：
- 输入：项目名、支线名、资产类型、本地文件路径
- 输出：本地路径、OSS key、public URL

### 3. 上传 OSS

使用 `scripts/upload_assets.py`：
- `--dry-run`：只检查文件存在性和目标路径，不真正上传
- `--upload`：真实上传
- 上传成功后生成 `upload_result.json`

### 4. 获取 public_url

上传成功后，public_url 可直接作为：
- 速创APIimage2.0 的 `character_refs`
- Minimax H3 的 `reference_image`
- 其他需要网络 URL 的生成工具输入

### 5. 被生成任务引用

将 public_url 填入生成配置文件，然后开始生成本地产物。

### 6. 产物归档

本地产物生成后，使用 `scripts/register_outputs.py` 上传到 OSS 对应目录。

### 7. 清单更新

每次上传/归档都会更新 `00_元数据/清单/` 下的 JSON 文件：
- `asset_manifest.json`：资产清单
- `upload_result.json`：上传结果
- `segment_asset_pack.json`：某个 SEG 的引用包

## 注意事项

1. **先解析，后生成**：生成任务启动前必须完成参考图的上传和 URL 确认。
2. **同名覆盖**：OSS 上传默认覆盖同名文件，上传前需确认版本。
3. **只管理新资产**：旧 `lexilearnoss/novel/...` 下的资产不迁移、不删除。
4. **凭证安全**：`.env` 文件禁止上传 Git 或分享。
