# 旧版归档规则

## 目的

在 AI 生成工作流中，同一张图片/音频可能会被反复重制。为了让当前目录始终只保留最新版、同时保留可追溯的历史版本，所有需要替换的资产都必须先归档旧版，再写入新版。

## 规则

### 1. 触发条件

以下情况必须执行旧版归档：

- 图片重新生成（如分镜图、人物锚点图、场景锚点图、故事板参考图等）。
- 音频重新生成（如 TTS 试听样本、已确认的参考音频等）。
- 参考图拼接文件、导演总表长图等产物被覆盖前。

### 2. 本地归档方式

假设当前目录下已有 `A.png`，现在要重新生成同名文件：

1. 在当前目录创建子文件夹 `旧版/`。
2. 将旧的 `A.png` 移入 `旧版/`，并改名为 `A_旧版v1.png`。
3. 如果 `旧版/` 中已有 `A_旧版v1.png`，则新归档为 `A_旧版v2.png`，依此类推。
4. 在 `旧版/` 中创建或追加 `说明.txt`，记录：
   - 归档时间
   - 原文件名
   - 归档后的文件名
   - 归档原因（如“人物服装不一致，重新生成”）

示例目录结构：

```text
panels/
├── SH-01.png              # 最新版
└── 旧版/
    ├── SH-01_旧版v1.png
    ├── SH-01_旧版v2.png
    └── 说明.txt
```

### 3. OSS 归档方式

`upload_assets.py` 在实际上传时，会检查 OSS 上是否已存在同名对象：

- 若存在，先把旧对象复制到同前缀的 `旧版/` 路径下，并添加版本号后缀。
- 然后删除原对象，再上传新版。
- 同时向 `旧版/说明.txt` 追加一条记录。

示例 OSS key 变化：

```text
video_workspace/英语项目/02_参考/支线/支线1/分镜图/SH-01.png
  ↓ 归档
video_workspace/英语项目/02_参考/支线/支线1/分镜图/旧版/SH-01_旧版v1.png
```

### 4. 调用方式

#### 本地归档

在生成新版之前调用：

```bash
python scripts/archive_local_version.py \
  --file "panels/SH-01.png" \
  --reason "人物服装不一致，重新生成"
```

#### OSS 归档

由 `upload_assets.py` 自动处理，无需手动调用。如需跳过，可指定 `--no-archive-old`：

```bash
python scripts/upload_assets.py \
  --manifest "清单/xxx_asset_manifest.json" \
  --upload \
  --no-archive-old
```

### 5. 说明文件格式

`旧版/说明.txt` 每一行格式如下：

```text
2026-08-24 15:41:19  SH-01.png -> SH-01_旧版v1.png  原因：人物服装不一致，重新生成
```

### 6. 注意事项

- 归档操作不可逆，执行前请确认旧版确实不再需要作为当前版本。
- 本地归档和 OSS 归档相互独立：本地归档后，新版文件路径不变；OSS 归档后，新版 public URL 与原 URL 相同。
- 如果某次重制只是临时测试，不想归档，可显式指定 `--no-archive-old` 或手动将测试文件保存到其他目录。
