# video_workspace OSS 目录结构规范

本规范定义 `oss://getwallet/lexilearnoss/video_workspace/` 下的目录层级，所有由 `/minimax-story-package` 管理的新上传资产必须按此结构存放。

## 根目录

```
oss://getwallet/lexilearnoss/video_workspace/
├── {项目名}/
└── TEST/
```

- `{项目名}`：使用项目中文名或项目内部约定名，例如 `英语项目`、`南极星`。
- `TEST/`：所有与正式项目无关、单独测试、临时生成的资产放在这里。

## 目录说明

| 目录 | 用途 |
|---|---|
| `00_元数据/清单/` | 存放资产清单、上传结果、SEG 资产包等 JSON/Markdown 文件 |
| `01_主线/` | 主线剧情专属资产或产出 |
| `02_参考/` | 所有作为 reference_image 使用的参考图 |
| `03_TTS/` | TTS 试听样本和人物/旁白音色参考；不存放正式台词音轨 |
| `04_支线产出/` | 最终生成的视频文件 |
| `TEST/` | 测试、实验、无关碎片 |

## 路径使用原则

1. **中文路径**：所有目录名使用中文，与用户需求保持一致。
2. **支线隔离**：不同支线的参考图、TTS、产出必须分开放置，禁止混用。
3. **文件名保持原意**：上传时文件名可使用英文 slug 或中文原名，但必须通过清单记录其含义。
4. **公共 URL**：`{PUBLIC_BASE_URL}/lexilearnoss/video_workspace/{项目名}/...` 即为图床可用 URL。
